SOMAFLOW PT STUDIO · WEB HOSTING & OPERATION MANUAL

소마플로우 (https://somaflow.kr)
GitHub & Vercel 무료 호스팅 · 도메인 연결 · 수정 가이드

본 문서는 소마플로우 홍보 웹사이트의 소스코드를 운영자 본인의 GitHub 및 Vercel 계정으로 이전하여 무료로 웹호스팅하고, somaflow.kr 개인 도메인을 연결하며, 추후 문구와 사진을 직접 수정·관리하는 전 과정을 안내합니다.

원본 GitHub 소스: https://github.com/jsy15757684/somaflow 연결 대상 도메인: https://somaflow.kr 월 서버 호스팅 비용: 무료 (0원 / SSL 보안인증서 자동 포함)
💡 시작 전 이해하기: 웹사이트가 운영되는 3단계 원리
1. 보관 및 수정

GitHub (깃허브)

웹사이트의 텍스트(index.html), 디자인(style.css), 스튜디오 사진을 보관하고 웹에서 바로 수정하는 무료 저장소입니다.

2. 무료 웹호스팅 서버

Vercel (버셀)

GitHub과 1:1로 연결되어, GitHub에서 글자를 고치면 15초 만에 자동으로 사이트에 반영해 주는 글로벌 고속 웹호스팅입니다.

3. 주소 연결

somaflow.kr 도메인

가비아·카페24 등에서 보유하신 somaflow.kr 도메인을 Vercel 서버와 연결하면 무료 HTTPS 보안 접속이 완성됩니다.

STEP 01

운영자 본인의 GitHub 계정으로 소스코드 가져오기

  • 1
    GitHub 회원가입 및 로그인

    https://github.com 에 접속하여 운영자 본인의 계정으로 회원가입(Sign up) 또는 로그인(Sign in)합니다.

  • 2
    소마플로우 원본 소스 저장소 접속

    브라우저 주소창에 https://github.com/jsy15757684/somaflow 를 입력하여 접속합니다.

  • 3
    [Fork] 버튼으로 내 계정에 1초 만에 복제하기

    화면 우측 상단에 있는 [Fork] 버튼을 클릭한 뒤, 다음 화면에서 초록색 [Create fork] 버튼을 누릅니다. 이제 https://github.com/본인아이디/somaflow 주소로 모든 웹사이트 파일이 본인 계정에 독립적으로 복사됩니다.

📌 참고 (소유권 완전 이전 또는 직접 업로드도 가능): Fork 대신 원본 제작자(jsy15757684)가 GitHub Settings → Transfer ownership 메뉴에서 운영자님 아이디로 저장소를 아예 양도하거나, 원본 페이지에서 [<> Code] → [Download ZIP]으로 파일을 내려받아 본인 새 저장소에 올려도 동일하게 작동합니다.
STEP 02

Vercel(버셀)에 가입하고 내 GitHub 저장소 배포하기

  • 1
    Vercel에 GitHub 계정으로 로그인

    https://vercel.com 에 접속하여 [Sign Up] → [Hobby (무료 플랜)] 선택 → 반드시 [Continue with GitHub] 버튼을 눌러 방금 만든 본인 GitHub 계정으로 연동 로그인합니다.

  • 2
    새 프로젝트 추가 (Add New Project)

    Vercel 대시보드 우측 상단의 [Add New...] 버튼 클릭 → [Project]를 선택합니다. (처음 연결 시 GitHub 권한 승인 창이 뜨면 All repositories 또는 somaflow를 선택하고 [Install / Authorize]를 누릅니다.)

  • 3
    somaflow 저장소 [Import] 및 [Deploy]

    Import Git Repository 목록에 보이는 somaflow 옆의 [Import] 버튼을 누릅니다. 다음 화면에서 아무 설정도 바꿀 필요 없이 하단의 [Deploy] 버튼을 클릭하면 약 20초 만에 웹사이트가 인터넷에 배포됩니다.

STEP 03

개인 도메인 (https://somaflow.kr) 연결하기

  • 1
    Vercel 프로젝트에 somaflow.kr 도메인 등록

    ① Vercel에서 배포된 somaflow 프로젝트 클릭 → 상단 탭 중 [Settings] 클릭
    ② 왼쪽 메뉴에서 [Domains] 클릭 → 입력창에 somaflow.kr 입력 후 [Add] 버튼 클릭
    ③ 팝업이 뜨면 첫 번째 권장 옵션인 Redirect www.somaflow.kr to somaflow.kr (Recommended)를 선택하고 [Add]를 누릅니다.

  • 2
    도메인 구매 업체(가비아, 카페24, 호스팅케이알 등)에서 DNS 레코드 2줄 입력

    somaflow.kr 도메인을 구매하신 사이트에 로그인하여 [DNS 관리 / 도메인 연결 / 레코드 설정] 메뉴로 이동한 뒤, 아래 표와 같이 A 레코드와 CNAME 레코드 2줄을 등록합니다.

레코드 타입 (Type) 호스트 / 이름 (Host) 값 / 위치 / 목적지 (Value / IP) 역할 및 설명
A @ (또는 공란) 76.76.21.21 https://somaflow.kr 기본 주소 연결
CNAME www cname.vercel-dns.com.
(가비아 등은 끝에 마침표 . 포함, 오류 시 마침표 제외)		 https://www.somaflow.kr 접속 시 기본 주소로 연결
✅ 연결 완료 확인 (무료 HTTPS 보안 인증서 자동 발급): 도메인 업체에서 위 2줄을 저장한 후 5분~30분 정도 기다리면, Vercel의 Settings → Domains 화면에 파란색/초록색 Valid Configuration 체크 표시가 켜지며 https://somaflow.kr 로 전 세계 어디서나 안전하게 접속됩니다. (기존에 다른 `@` A레코드가 있었다면 충돌 방지를 위해 삭제해 주세요.)
STEP 04

코딩 프로그램 없이 웹에서 문구·시간·사진 직접 수정하기

GitHub과 Vercel이 연결되어 있으므로, GitHub 웹사이트에서 글자나 사진을 수정하고 저장(Commit)만 누르면 15초 뒤에 https://somaflow.kr 에 자동으로 반영됩니다.

  • A
    문구, 운영시간, 주소, 프로그램 설명 수정하는 법 (index.html)

    ① 본인 GitHub의 somaflow 저장소에서 index.html 파일을 클릭합니다.
    ② 파일 화면 우측 상단의 연필 모양 아이콘 (Edit this file)을 클릭합니다. (꿀팁: 키보드에서 마침표 . 키를 누르면 웹 전용 편집기가 열려 더 편하게 수정할 수 있습니다.)
    ③ Ctrl + F (맥은 Cmd + F)로 바꾸고 싶은 한글 문구(예: 10:00 ~ 21:00, 대흥동 등)를 찾아 원하는 내용으로 수정합니다.
    ④ 화면 우측 상단 초록색 [Commit changes...] 버튼 클릭 → 팝업에서 다시 [Commit changes]를 누르면 15초 후 실제 사이트에 자동 반영됩니다!

  • B
    스튜디오 사진 교체하는 법 (public/images 폴더)

    ① GitHub 저장소에서 public 폴더 → images 폴더로 들어갑니다.
    ② 우측 상단 [Add file] → [Upload files]를 누르고, 아래 표의 파일 이름과 동일한 파일명으로 새 사진을 드래그하여 업로드한 뒤 하단 [Commit changes]를 누르면 즉시 새 사진으로 바뀝니다.

🎨 디자인 색상이나 글자 크기를 바꾸고 싶을 때 (css/style.css): css/style.css 파일 맨 위쪽 :root { ... } 영역에서 배경색(--lcx-bg: #FCFBF8), 글자색(--lcx-ink: #2B2724), 골드 포인트 색상(--lcx-gold: #A8862B) 코드만 변경하면 사이트 전체 톤앤매너가 한 번에 변경됩니다.
STEP 05

1:1 방문 상담 신청 내역 — 구글 스프레드시트 자동 저장 & 이메일 실시간 알림 연결

  • 1
    구글 스프레드시트 생성 및 Apps Script 코드 붙여넣기

    ① https://sheets.new 에 접속하여 새 구글 스프레드시트를 만들고 제목을 소마플로우 상담신청 내역으로 저장합니다.
    ② 상단 메뉴 [확장 프로그램] → [Apps Script]를 클릭합니다.
    ③ 기존 코드를 지우고, GitHub 저장소에 포함된 google_apps_script.js 파일의 내용을 그대로 복사해 붙여넣은 뒤 저장(Ctrl+S)합니다. (특정 이메일로 알림을 받고 싶다면 상단 NOTIFY_EMAIL = "본인이메일@naver.com"에 입력)

  • 2
    웹 앱(Web App)으로 배포하여 전용 URL 발급받기

    ① Apps Script 우측 상단 [배포] → [새 배포] 클릭 → 왼쪽 톱니바퀴(유형 선택)에서 [웹 앱] 선택
    ② 다음 사용자 인증 정보로 실행: 나(Me) / 액세스 권한이 있는 사용자: 반드시 모든 사용자(Anyone) 선택 후 [배포] 클릭
    ③ [액세스 승인] → 본인 구글 계정 선택 → [고급] → [안전하지 않은 페이지로 이동] → [허용] 클릭 후 생성된 웹 앱 URL(https://script.google.com/macros/s/.../exec)을 복사합니다.

  • 3
    GitHub의 js/main.js 파일에 웹 앱 URL 붙여넣기 (연동 완료!)

    본인 GitHub 저장소의 js/main.js 파일을 열고 맨 윗줄 const GOOGLE_SCRIPT_URL = "여기에_웹앱_URL_붙여넣기"; 에 복사한 주소를 넣은 뒤 [Commit changes]를 누르면, 이후 모든 상담 신청이 구글 시트에 자동 기록됨과 동시에 운영자 이메일로 실시간 알림이 발송됩니다!
